## 2. 사용자(관리자)가 Supabase에서 할 일

이건 코드가 아니라 대시보드에서 하는 일이다. 키나 비밀값은 저장소에 적지 않는다.

1. SQL Editor에서 `db/migrations/008_master.sql`을 Run한다.
2. 마스터로 쓸 계정의 `auth.users.id`를 찾아서 `insert into masters (player_id, note) values ('<id>', 'owner');`를 Run한다.
   - 카카오 계정은 이메일이 비어 있을 수 있어서 id로 넣는다.
   - 이메일 계정과 카카오 계정은 서로 다른 계정이다.
3. Edge Functions에서 `bori-talk`에 `db/functions/bori-talk/bundle.js`를 다시 붙여 넣고 Deploy한다(패킷 v2.0).
   - 다시 만들려면 `node tools/build-functions.mjs`.
4. 입장코드는 Table Editor의 `invite_codes`에 직접 추가한다.

## 4. 작업 방법 (이 PC 기준)

```bash
corepack pnpm install
node node_modules/typescript/bin/tsc --noEmit
corepack pnpm test:unit
STATIC_EXPORT=1 corepack pnpm build
```

- **e2e**:
  - 이 PC에서는 dev 서버가 miniflare 오류로 죽는다. 정적 빌드(`dist/client`)를 5173 포트로 띄우고 `npx playwright test tests/e2e/proto3d...`로 돌린다.
  - 한꺼번에 돌리면 이 PC가 느려서 네트워크 끊김이나 trace zip 오류가 섞인다. `--workers=1`로 나눠 돌릴 것.
  - 데스크톱 "the 3D garden renders and a tree opens its card"는 이 변경들 전부터 이 PC에서 실패한다(원인 미확인).
- **배포**: `npx netlify deploy --prod --no-build --dir dist/client --site <사이트 id>`. 사이트 id는 `docs/deploy.md`에 있다.
- **3D 값**은 `app/proto3d/look.ts`, **시간 값**은 `app/core/timing.ts`에 둔다(CLAUDE.md 규칙).
- **Blender**: `tools/blender/*.py`(캐릭터 `analysts.py`, 꽃·나무 `kind_trees.py`, 그림 `portrait.py`·`faces.py`·`bori_faces.py`). 렌더 출력 경로는 절대 경로로 줘야 한다.
- **테스트용 창 변수**(fixtures가 기본으로 켬): `__noLanding`, `__noTutorial`, `__noIntro`, `__localAuth`. 그 밖에:
  - `__boriOpen`(보리 서버 대역)
  - `__priceFixture`(시세 대역)
  - `__fishBite`·`__fishWindow`·`__fishPick`(낚시 고정)
  - `window.__proto3d`의 `friendAt`, `boriFace`, `view`(fp·follow), `plantAt`, `decor`, `fishing`
- **커밋**은 사용자가 하라고 할 때만, 메시지는 `[tag] 요약` 형식으로 한다. 토큰·키·개인 이메일은 저장소에 적지 않는다.
