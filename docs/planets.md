# 다른 정원들 (2026-11-14)

내 정원을 작은 행성으로, 같은 리그 그룹 사람들의 정원을 하늘에 떠 있는 행성으로 보여주는 기능이야. 목업은 `docs/mockups/planets.html`.

## 어디서

- 지도 시트 아래 "하늘 보기 · 다른 정원들", 또는 주소 `?sky`.
- 열면 카메라가 내 정원에서 뒤로 빠지며 밤하늘이 나와. 정원은 그동안 안 그려(`Scene3D` world.sky).
- 행성(또는 이름표)을 누르면 그쪽으로 날아가고 방문 시트가 열려. 내 행성을 누르면 공개 범위 시트.

## 보이는 것, 안 보이는 것

| 공개 범위 | 하늘에 | 보이는 것 |
|---|---|---|
| 비공개 | 안 뜸 (나한테는 내 행성이 보임) | 리그 순위의 이름만 |
| 이름 가림 (기본) | 뜸 | 나무 상태(꽃 핌·튼튼·신호·시듦·썩어 감·그루터기), 업종, 판정 적중률, 확신 보정, 원정 최고, 도장 수, 칭호, 습관 별명 |
| 종목 공개 | 뜸 | 위 + 종목 이름 |

- 어떤 경우에도 안 나가는 것: 금액, 수량, 수익률, 판단 메모, 캡처한 화면. `core/planets.ts` `wireOf`가 밖으로 나가는 유일한 모양이고, 테스트(`tests/planets.test.mjs`)가 이걸 막아.
- 나무 색은 오르고 내린 정도를 대략 보여줘. 시트에 그렇게 적어 두었고, 싫으면 비공개.
- 업종은 지금 정원이 쓰는 세 갈래(기술·부품 / 소비재 / 콘텐츠)야. 실제 업종 데이터가 붙으면 바꿔.

## 서버

- 지금은 예시 이웃 7명(`examplePlanets`, 주마다 바뀜, "예시 행성 · 서버 연결 전" 표시)이고, 내 행성은 아무 데도 안 보내.
- 붙일 때: `app/proto3d/server.ts` `planetRepo`를 `supabasePlanets(url, anonKey, token)`으로. 스키마는 `db/schema.sql` 맨 아래(`planets`, `planet_neighbours` 뷰: 같은 리그 그룹의 공개 행성만, `planet_cheers`: 이웃당 주 1번).
- 응원 도장은 지금 화면 안에서만 찍혀. 서버가 붙으면 `planet_cheers`에 남겨.
