# 관측소 원정 플레이 테스트 (G6)

G6은 사람이 직접 해 봐야 끝나는 단계야. 2~3명에게 한 판씩 시키고, 아래를 보고 적어. 결과는 맨 아래 표에 남기고, 조정은 "바꿀 값"에서 한 번에 하나씩만 바꿔.

## 준비

- 휴대폰 세로로. 주소: `/?game=<판 id>`(같은 판으로 비교하려면) 또는 관측소 문 → 이번 주 판.
- 판 id는 `public/game/packs/index.json`에 있어. 처음 하는 사람에겐 `08b8c477`(2017년 여름~가을, 대한광통신 최대주주 변경)을 추천.
- 설명은 한 줄만 해: "옛날 진짜 주식 시장이야. 언제인지 모르고 해 보고, 끝에 맞혀 봐." 나머지는 말하지 말고 지켜봐.

## 지켜볼 것

| 장면 | 볼 것 |
|---|---|
| 브리핑 | 시작까지 몇 초? 칩이 뭔지 묻나? |
| 흐름 | "빠르게"·"다음 순간까지"를 누르나? 누르면 언제? 뉴스에 핀을 꽂나? 호가창을 보나, 무시하나? 매수·매도 ¼을 눌러 보나? |
| 결정 순간 | 셋의 줄을 다 읽나? 차트 주석을 보나? 칩을 몇 개 거나(늘 1개? 늘 4개?) 30초 시계에 쫓기나? |
| 교체 | 찢어지는 카드를 보고 반응하나? 새 회사가 뭔지 궁금해하나? |
| 공개 | 연도 도장에서 "오!"가 나오나? 점수와 수익이 반대일 때 헷갈려하나? "그때 몰랐던 것"을 여나? |
| 끝 | "다시 하기"를 누르나? 정원으로 가서 "닮은 장면"을 눌러 보나? |

## 끝나고 물어볼 것 (세 개만)

1. 언제쯤이라고 생각했어? (맞혔는지, 뭘 보고 짐작했는지)
2. 제일 오래 고민한 결정은? 왜?
3. 한 판 더 할래? (안 하겠다면 이유)

## 숫자로 남는 것

판이 끝나면 `localStorage`의 `rethink-garden-v1` → `expeditions`에 결정·칩·결과·누구 쪽으로 갔는지가 남아. 사람마다 복사해 두면 비교할 수 있어.

## 바꿀 값

| 느낌 | 값 | 위치 |
|---|---|---|
| 흐름이 지루하다 / 너무 빠르다 | `gameDay` 3000ms, `gameFast` 4배 | `app/core/timing.ts` |
| 결정이 쫓긴다 / 늘어진다 | `gameDecide` 30000ms | `app/core/timing.ts` |
| 셋의 줄이 너무 늦게 / 빨리 뜬다 | `gameFreeze` 900ms, `gameRead` 650ms | `app/core/timing.ts` |
| 칩이 남는다 / 모자란다 | `CHIPS` 10, `MAX_STAKE` 4 | `app/core/game/run.ts` |
| 비김이 너무 많다 / 적다 | `TIE_PP` 2%p, `HORIZON` 20일 | `app/core/game/grade.ts` |
| 결정이 너무 많다 / 적다 | 판당 결정 3~5(지금은 모두 5) | `tools/game/build-packs.mjs` 다시 빌드 |
| 공개가 길다 | `gameReveal` 380ms | `app/core/timing.ts` |
