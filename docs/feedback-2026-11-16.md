# 피드백 (2026-11-16, 팀 테스트)

받은 그대로 적고, 묶음과 순서를 붙였다. 진행하면 상태를 고친다.

## 받은 그대로

1. 과일 / 꽃 나무로 변경
2. 뿌연 거 개선
3. 맵이 조금 더 넓게 (지금 너무 옹기종기한 느낌)
4. 투자일지 쓰기 너무 많고 귀찮음
5. 너무 많음
6. 게임 너무 지루함
7. 퀴즈 추가 (최근 뉴스 받아서 "이런 일이 있었을까요? 없었을까요?", 경제 명제로 "이러한 경향이 있을까요? 없을까요?")
8. 오늘의 퀘스트 (동전 얻기) + 출석체크
9. 퀘스트 깰 때마다 기능 오픈 (투자일지)
10. 나무를 꽃/나무 가게에서 살 수 있게 → 이걸로 심으면 훨씬 더 예쁜 정원
11. 캐릭터가 건물을 통과함 → 고치기
12. 일상 일기·일지·투자일지 상위 랭킹 앱을 보고, 일기 앱이 사용자를 잡는 전략 반영
13. 커스텀 페이지 왼쪽 위 글씨 겹침
14. 코인을 화면 위에 쉽게 보이게
15. 건물을 보고 무슨 건물인지 모르겠음 → 튜토리얼에 넣거나 건물에 표지판
