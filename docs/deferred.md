# 넘어간 것

기능 구현을 먼저 하기로 해서(2026-11-10 사용자 결정) 뒤로 미룬 것들이야. 꾸미기는 기능에 꼭 필요한 부분만 하고 넘어가.

다시 할 때는 이 파일에서 골라 단계로 잡고, 끝난 줄은 지워.

## 꾸미기 (ux-spec 5장, 11.9)

| 무엇 | 스펙 | 지금 상태 | 다시 할 때 필요한 것 |
| --- | --- | --- | --- |
| 창문 커튼 바꾸기 | 5장 집 표면 | 없음 | 커튼 그림, 창문 위치별로 올리기 |
| 지붕 색 바꾸기 | 5장 집 표면 | 없음. 외벽은 기본·장미 두 가지만 됨 | 외벽 그림처럼 색만 다른 집 그림(나노바나나) |
| 외벽 하늘색 | 022 | 만들지 않기로 함 | 022 프롬프트 4·5번 그대로 쓰면 됨 |
| 길 타일 더 (나무 데크·자갈) | 5장 정원 | 흙길·디딤돌·꽃밭만 있음 | 172×86 바닥 칸 그림 |
| 생울타리·덤불, 연못 | 5장 정원 | 없음 | 그림, 여러 칸 가구 규칙으로 놓기 |
| 우편함 모양 바꾸기 | 5장 정원 | 없음 | 우편함 그림 몇 가지 |
| 세트 보너스 (같은 테마 3개) | 5장 | 없음 | 테마 정하기, 작은 연출 |
| 손 슬롯 옷, 친구에게 선물 입히기 | 5장 옷 슬롯 | 저장 자리(`hand`)만 있음 | 손에 드는 옷 그림, 친구 착용 레이어 |
| 추억 앨범 자동 스냅샷·사진 찍기 | 5장 수집과 도감 | 성취 카드만 있음 | 장면 저장 방식 정하기 |
| 침대·책상 같은 2칸 가구 더 | 5장 가구 | 2칸은 벤치 하나 | 가구 그림 |
| 2층·다락 벽지 위 창문 화면 확인 | 022 | 겹쳐 보기로만 확인함 | 2층·다락에서 벽지 바르고 스크린샷 |

## 반응감 (ux-spec 7장)

| 무엇 | 지금 상태 |
| --- | --- |
| 마우스 올림 외곽선 하이라이트 | 1.04배 커지기만 함 |
| 바람에 풀·나무 흔들림, 낮 꽃잎, 구름 그림자 | 없음 |
| 친밀도 단계가 오를 때 화면 가장자리 빛 | 하트와 반짝이만 있음 |
| 선물 열기: 상자 흔들림 → 리본 풀림 → 아이템 등장, 익명이면 별 파티클 | 흔들리다 반짝이며 열리기만 함 |

## 소리 (ux-spec 7장, docs/sound-map.md)

| 무엇 | 지금 상태 |
| --- | --- |
| 비어 있는 소리 자리 채우기 | 75곳 중 51곳 비어 있음 |
