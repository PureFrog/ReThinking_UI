# 넘어간 것

> 한눈에 보는 정리(만든 기능·남은 일·디자인·소리)는 `docs/features.md`. 여기는 항목별 세부 표야.

기능 구현을 먼저 하기로 해서(2026-11-10 사용자 결정) 뒤로 미룬 것들이야. 꾸미기는 기능에 꼭 필요한 부분만 하고 넘어가.

다시 할 때는 이 파일에서 골라 단계로 잡고, 끝난 줄은 지워.
