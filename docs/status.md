## 3. 미뤄 둔 것과 푸는 법

### 카카오 로그인 KOE205
원인: Supabase가 요청하는 동의항목(닉네임·프로필 사진·이메일)이 카카오 앱에 안 켜져 있음.
푸는 법: developers.kakao.com → 내 애플리케이션 → 카카오 로그인 → 동의항목에서 닉네임(필수), 프로필 사진(선택), 카카오계정 이메일(선택)을 켠다. 이메일이 막혀 있으면(비즈 앱 아님) 그 화면을 캡처해 주면 Supabase 쪽에서 "이메일 없는 사용자 허용"으로 우회한다.

### 구글 로그인 후 첫 화면으로 돌아옴
원인 추정: 시작한 주소와 돌아온 주소가 다름(localhost ↔ 127.0.0.1)이거나 Redirect URLs에 없음 → 로그인 코드 교환 실패.
푸는 법: 한 주소(`http://localhost:5173`)로만 열고, Supabase URL Configuration에 `http://localhost:5173/**`가 있는지 확인. 다시 실패하면 첫 화면 로고 아래 빨간 안내 문장을 그대로 보내 준다(실패 이유가 찍히게 해 둠).
배포하면 Netlify 주소도 Redirect URLs에 넣어야 한다.

### 그 밖에 미뤄 둔 것
- 카카오 연결 끊기 웹훅(사용자가 카카오에서 앱 연결을 끊으면 우리 계정도 정리) — 플레이스토어 전에.
- 보리 이름은 임시. 확정 필요.
- 지기 화면 가로(844×390)·데스크톱(1400) 스크린샷 확인 안 함.

## 5. 하는 순서 (추천)

1. **커밋 나눠 하기** (사용자 OK): `[brand]`·`[glass]` → `[server]` → `[J1]`~`[J3]` → `[docs]`. 그다음 푸시. 지금 150여 파일이 한 번에 날아갈 위험이 있다.
2. **로그인 마무리** (localhost): 카카오 동의항목, 구글 주소 확인 → 다시 시도 → 안 되면 빨간 안내 문장 공유.
3. **Supabase 마무리**: SQL Editor에서 `db/migrations/002_saves_and_delete.sql`, `003_jigi.sql` 실행 → Edge Functions에 `friend-chat`, `jigi-llm` 붙여 넣기 → 시크릿 `OPENAI_API_KEY`. (`docs/server.md` 10~12)
4. **Netlify 첫 배포** (`docs/deploy.md`): 저장소 연결(팀원 저장소면 주인이 Netlify 앱 허락), 환경 변수 2개, Supabase에 Netlify 주소 추가, 배포 주소에서 로그인·동기화 확인.
5. **팀원 초대해서 같이 써 보기**: 각자 가입 → 이 시점에 Realtime 접속 표시와 리그 실제 유저 연결을 붙인다.
6. **실제 데이터**: KRX 가격부터(지기 판정이 진짜가 됨), 그다음 모델 신호.
7. **게임 서버 결정**: 팀원 게임 방식 확인 → 필요하면 Fly.io/Render에 Colyseus.
8. **플레이스토어 준비**: 약관·방침 본문, TWA, 데이터 보안.
