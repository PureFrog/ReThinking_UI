# 문구 정리 (전 → 후) — 2026-11-14 승인, 반영함

2026-11-14 피드백: 시적인 단어(도장·하늘로·관찰자 N급·성향 문장)가 어색하고 AI 같다. 그렇다고 브론즈·다이아 같은 e스포츠 말투도 안 맞는다.
고른 기준: **깔끔한 앱 말투**(증권앱·토스처럼 짧고 평범한 단어), **등급은 애널리스트 직급**.

## 원칙

- **화면 문구(버튼·제목·안내)는 해요체.** 짧게, 평범한 단어로.
- **캐릭터 대사만 반말.** 토리·모아·루온(+기니피그)이 각자 성격대로 말한다. 숫자와 사실을 짚는다.
- 비유는 3D 화면에 실제로 보이는 것에만 쓴다(나무). 캡슐·씨앗·꽃·도장·편지 같은 말은 화면 문구에서 뺀다.
- 사람을 성격으로 부르지 않는다("과감한 버팀꾼" X). 숫자로 보여준다.
- 매매 권유·가격 예측 금지는 그대로.
