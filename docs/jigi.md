# 지기 투자일지 적용 (2026-11-15)

투자일지를 팀원의 지기(知己) 명세로 바꾼다. 근거 문서는 카카오톡으로 받은 두 파일이다.
- `지기 투자일지 프로토타입 (1).html`: 화면과 규칙의 기준
- `지기_3D프런트_적용_v0.2.md`: 우리 앱에 맞추는 법

화면은 지금 우리 앱 방식을 따른다. 3D 정원 위 유리 시트를 쓰고, UI 문구는 해요체, 캐릭터만 반말이다. 문서의 종이 재질·반말 UI는 따르지 않는다.

## 정한 것 (사용자, 2026-11-15)

| 주제 | 결정 |
|---|---|
| 기존 판단 루프 | 새 판단을 만드는 길을 닫는다. 이미 있는 판단과 30·90일 채점은 남은 것만 끝내고 "이전 판단"에서 읽기만 한다. |
| 리그·직급 점수 | 과정 점수: 일지 저장, 가설 확정, 판정 뒤 복기, 과제 실천 (J3) |
| 분석 위치 | 일지 탭 안 `일기장 · 분석` 두 칸 |
| 작성 화면 | 4쪽 넘기기(오늘의 나 → 종목과 차트 → 가설 → 기한과 확신), 쪽마다 프로토타입의 빈칸 문장 |
| 데모 종목 | 프로토타입의 실제 KRX 이름 + 모의 시세. 데모 정원 7그루는 받침 없는 이름(SK하이닉스·NAVER·카카오·현대차·한화에어로스페이스·삼성전자·POSCO홀딩스)으로 바꿔서 조사가 안 깨진다. |
| 시간 이동 버튼 | 시뮬레이션용이라 서비스에는 넣지 않는다. 테스트는 `?ahead=N` |
| 수동 판정 버튼 | 프로토타입에서만 수동이다. 실제는 자동 판정. 주가 방향 가설은 기간 끝 종가로 판정하고, 그 밖의 가설은 "자동 판정 준비 중"으로 둔다(서버 자료가 붙으면 자동). |
| 손절 검토 칩 | "한 일"은 보유로 두고 손절·청산 계획 칸을 연 채로 연다(적용 문서 3.1 (가)). |

## 코드 위치

- `app/core/jigi/stocks.ts`: 12종목, 모의 일봉(프로토타입 합성 시세를 2026-11-13 종가가 실제 수준이 되게 맞춤), 확정 종가
- `app/core/jigi/journal.ts`: 일지 모델, 필수 9칸, 저장·버전, 빠른 칩, 책장 묶기, 휴지통 30일
- `app/core/jigi/hypothesis.ts`: 판정(주가 방향만 자동, 종료일 종가 vs 확정 당시 종가)
- `app/core/jigi/seed.ts`: 데모 일지 13편(예시 표시, 통계에 안 섞음)
- `app/proto3d/ui/JigiBook.tsx`: 일지 탭(신호·이전 판단 채점·종목별 책장·시간 막대·작성 중·복기·보관·휴지통·상세)
- `app/proto3d/ui/JigiWrite.tsx`: 4쪽 작성. 입력은 바로 저장 상태(`GardenSave.journals`)에 들어가서 닫거나 화면을 돌려도 남는다.
- `app/proto3d/ui/JigiChart.tsx`: SVG 일봉, 기록 위치 표시
- `app/core/jigi/extract.ts`: 규칙 기반 가설 추출(프로토타입 규칙, 단 주가·종목명이 없는 문장은 주가 가설로 보지 않음), 확정 규칙
- `app/core/jigi/capsules.ts`: 나무마다 캡슐 하나(열지 않은 판정 먼저, 아니면 가장 가까운 D-n). 옛 판단 캡슐과 섞일 때는 옛 판정 도착이 먼저.
- `app/proto3d/ui/JigiHypos.tsx`(가설 편집·복기), `JigiVerdict.tsx`(판정 공개)
- `app/core/jigi/analysis.ts`: 분석(Wilson 95% 구간, 3건 미만은 추가 관찰 필요, 유형, 보완할 점 최대 3개·과제, 판단 변화, 학습 후 변화). 내 일지가 없을 때만 예시 일지로 보여 주고 그렇다고 표시. 연습 일지는 안 셈.
  - **유형(2026-11-19 사용자 결정)** = 그 투자자가 어떤 스타일로 판단하는지. 일지에 쓴 것으로만 정한다(무엇을 근거로 · 얼마나 길게 · 확신을 거는 방식 · 주로 하는 일 · 반대쪽 생각 · 생각을 바꾸는 정도 → 예: "실적을 근거로 길게 보는 신중형"). 적중률은 유형을 정하는 데 쓰지 않고 참고로만 보여 준다. 일지 3편 미만이면 말하지 않는다.
  - 숫자에서 나온 고칠 점(실적→주가 연결, 높은 확신의 근거, 기간별 차이, 반복해서 빗나간 분야)은 유형이 아니라 '과제' 탭의 **보완할 점**이고 각각 공부 과제를 단다.
- `app/core/jigi/points.ts`: 과정 점수(일지 저장 3, 가설 확정 2(일지당 3개까지), 복기 3, 과제 실천 2) → 주간 리그(`weekPoints`의 work), 직급 경험치(`xpOf` work). 적중은 점수가 아니다. 이미 받은 옛 채점 점수는 그대로.
- 월간 리포트(`core/letter.ts` jigi): 이달 일지·가설 판정·복기가 먼저, 옛 판단은 한 줄.
- `app/proto3d/ui/JigiStats.tsx`: 일지 탭 '분석' 7칸
- `app/proto3d/jigi.css`
