# 024-v2 나노바나나 다시 돌릴 것: 땅 타일 (저녁·밤)

- 요청일: 2026-11-10
- 요청자: Claude
- 돌릴 횟수: 입력 5장 × 저녁·밤 = 10번

## 왜 다시

024에서 집·마당 소품·밭은 잘 들어왔어. 땅 타일만 다시 받아야 해.

- 한 시트에 같이 넣었더니 빛이 왼쪽에서 오른쪽으로 흘러서, 풀 타일 네 장의 밝기가 서로 달라졌어. 마당에 깔면 체스판처럼 보여.
- 타일마다 테두리 선이 생겼고, 가장자리 타일 두 장은 옆면이 양쪽 다 생겼어.
- 오른쪽 가장자리 타일 옆면에 반짝이 표시(✦)가 찍혀 있어.

## 보내는 방법

1. 입력과 프롬프트는 `024-v2-ground/`에 있어. 타일 한 장씩 따로 들어 있어.
2. 입력 한 장 + 프롬프트 A(저녁) → 저장, 같은 입력 + 프롬프트 B(밤) → 저장. 다섯 장 모두.
3. 결과는 `public/assets/incoming/024-nb/`에 `<번호>_<이름>_sunset.png`, `<번호>_<이름>_moonlit.png`로 저장해. 예: `1_ground_grass_1_moonlit.png`
4. 풀 타일은 한 장만 받아서 네 가지 풀 타일에 똑같이 써. 풀 타일끼리는 풀 몇 포기만 다르고, 밤에 밝기가 하나로 맞는 게 더 중요해.

## 입력

| 번호 | 입력 | 무엇 |
| --- | --- | --- |
| 1 | `1_ground_grass_1.png` | 풀 타일 |
| 2 | `2_ground_path.png` | 흙길 |
| 3 | `3_ground_stepping_stone.png` | 디딤돌 |
| 4 | `4_ground_edge_left.png` | 마당 왼쪽 가장자리 (옆면 하나) |
| 5 | `5_ground_edge_right.png` | 마당 오른쪽 가장자리 (옆면 하나) |

## 확인할 것

- 타일 안에서 밝기가 한쪽으로 쏠리지 않았는지
- 테두리 선, 반짝이 표시가 없는지
