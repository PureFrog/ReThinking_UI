# 024 나노바나나 요청: 저녁·밤 그림 (바깥 바탕)

- 요청일: 2026-11-10
- 요청자: Claude
- 왜 나노바나나: 이미 있는 그림을 **모양·위치 그대로 두고 빛만** 저녁·밤으로 바꾸는 편집이야.
- 범위 (사용자 결정 2026-11-10, 안 '가'): 집 바깥, 마당 소품, 밭, 땅 타일. 나무·캐릭터·집 안 방과 가구는 낮 그림 그대로 둬 (집 안은 불 켠 방으로 봄).
- 돌릴 횟수: 입력 7장 × 저녁·밤 = 14번

## 보내는 방법

1. 입력 그림과 프롬프트는 `024-daypart/`에 있어. 입력은 비슷한 것끼리 한 장에 모아 둔 시트야.
2. 입력 그림 한 장 + 프롬프트 A(저녁) → 저장, 같은 그림 + 프롬프트 B(밤) → 저장. 일곱 장 모두 이렇게.
3. 결과는 `public/assets/incoming/024-nb/`에 `<번호>_<이름>_evening.png`, `<번호>_<이름>_night.png`로 저장해. 예: `3_farm_night.png`
4. Claude는 시트를 원래 크기로 맞춘 뒤 칸마다 잘라서 **낮 그림의 윤곽(투명 부분)을 그대로** 씌워. 그림 자체는 고치지 않아. 그래서 모양이 조금 달라지면 그 부분은 잘려 나가.

## 입력

| 번호 | 입력 그림 | 들어 있는 것 |
| --- | --- | --- |
| 1 | `1_ground.png` | 땅 타일 8장 (풀 4, 흙길, 디딤돌, 마당 가장자리 둘) |
| 2 | `2_yard.png` | 꽃 덤불 둘, 우편함, 씨앗박스, 삽, 팻말 |
| 3 | `3_farm.png` | 밭 둘, 울타리 둘, 문, 우물, 창고, 손수레, 퇴비, 비료 포대, 허수아비 |
| 4 | `4_house_small.png` | 작은 집 바깥 |
| 5 | `5_house_small_rose.png` | 작은 집 바깥 (장미 외벽) |
| 6 | `6_house_grown.png` | 커진 집 바깥 |
| 7 | `7_house_grown_rose.png` | 커진 집 바깥 (장미 외벽) |

## 프롬프트

- A 저녁: `024-daypart/A_저녁_프롬프트.txt`
- B 밤: `024-daypart/B_밤_프롬프트.txt`

## 잘 안 됐을 때

- 배경 마젠타가 어두워지거나 물들면: 그대로 줘도 돼 (윤곽은 낮 그림에서 가져와).
- 물건이 움직이거나 하나 더 생기면: 그 장만 다시 돌려.
